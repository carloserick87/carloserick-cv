# Carlos Erick - CV

`carloserick-cv` is a command-line application that provides an interactive way to explore my professional resume,
including my experience, education, technical skills, projects, and contact information.

Built with TypeScript and Node.js, this project makes my professional profile accessible directly from the terminal.

## Features.
 - **About me:** Professional profile and introduction.
 - **Education:** Academic background and qualifications.
 - **Experience:** Work history and professional experience.
 - **Skills:** Technical skills, tools, and technologies.
 - **Projects:** Personal and learning projects.
 - **Contact:** Professional contact information.

## Usage
  Run the following command in your terminal:

 ```bash
  npx carloserick-cv
 ```

## Technologies
  * TypeScript
  * Node.js
  * NPM
  * Chalk
  * Inquirer
  * Figlet
  * Gradient-string
